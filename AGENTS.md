# Java Service Agent Instructions

## Mandatory Java Code Style

Before creating or modifying any Java source file, read and follow:

[docs/java-code-style.md](docs/java-code-style.md)

All formatting rules R01–R19 are mandatory.

These rules apply to:

- Production Java source code.
- Unit and integration tests.
- Controllers and REST resources.
- Services and repositories.
- Security and configuration classes.
- Filters, interceptors, and utilities.

## Implementation Requirements

1. Read the complete Java Code Style document before coding.
2. Apply all rules during implementation.
3. Prioritize readability on a 15-inch laptop.
4. Target 80 characters per line.
5. Keep ordinary Java lines within 100 characters.
6. Use 120 characters only for unavoidable exceptions.
7. Avoid horizontally compressed fluent APIs and lambdas.
8. Preserve business logic and existing behavior.
9. Avoid unrelated refactoring or formatting changes.
10. Review every modified Java file for R01–R19 compliance
    before completing the task.

## Final Verification

Before reporting completion:

- Check the formatting of all modified Java files.
- Correct any violations introduced by the task.
- Confirm that the required style documentation exists.
- Do not claim compilation or tests passed unless executed.
